# Contributing to NeuroCare AI

Thank you for your interest in contributing to NeuroCare AI.

## How to Contribute

1. **Fork** the repository.
2. **Clone** your fork locally.
3. Create a new **feature branch** from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. Make your changes and **test** them locally.
5. **Commit** with a clear message:
   ```bash
   git commit -m "Add: brief description of your change"
   ```
6. **Push** to your fork and open a **Pull Request**.

## Development Setup

Please refer to the [Setup Guide](docs/SETUP.md) for detailed instructions on running the project locally.

## Guidelines

- Follow the existing code style and project structure.
- Do not commit `.env` files, credentials, or sensitive information.
- Test your changes with the backend running and a local MySQL database.
- Write clear commit messages describing what changed and why.

## Reporting Bugs

- Open a GitHub Issue with a clear title and description.
- Include steps to reproduce the problem.
- Mention your operating system, Node.js version, and MySQL version.

## Code of Conduct

Be respectful and professional. This is an academic healthcare project — treat contributors and users with courtesy.

## Questions?

Open an issue or reach out to the project maintainer.
